# Screenshots

Add your Power BI dashboard page screenshots to this folder.

Suggested naming:
- `page1-passenger-analysis.png`
- `page2-sales-performance.png`
- `page3-railway-performance.png`
- `page4-route-analysis.png`

Once added, reference them in the main [README.md](../README.md), e.g.:

```markdown
![Passenger Analysis](./screenshots/page1-passenger-analysis.png)
```
