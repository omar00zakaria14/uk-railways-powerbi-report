# DAX Workbook

Add your Power BI dashboard workbook file here.

Suggested files:
- `Report.pbix` — the full Power BI Desktop file
- `dax-measures.dax` or `dax-measures.txt` — exported plain-text copy of all DAX measures (useful for version control, since `.pbix` is binary and doesn't diff well in Git)

For the full written reference of all 69 DAX measures with formulas and descriptions, see [`/docs/measures.md`](../docs/measures.md).
